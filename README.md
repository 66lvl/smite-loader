# SMITE 2 Loader

Портативный лоадер для локальной сборки DLL и обновления SDK через Dumper-7.

## Скачать

1. Откройте [релиз v2.0.2](https://github.com/66lvl/smite-loader/releases/tag/v2.0.2) и скачайте `SmiteLoader-portable.zip`.
2. Распакуйте архив в отдельную папку, например на рабочем столе.
3. Запустите `SmiteLoader.exe` и подтвердите начальную подготовку. GitHub-аккаунт не нужен.
4. Проект загрузится в `%USERPROFILE%\AppData\LocalLow\SmiteLoader\project`. Dumper-7 и собранная DLL появятся рядом с лоадером.

Нужны Windows, интернет и Visual Studio Build Tools с MSVC и Windows SDK. При отсутствии компонентов лоадер покажет список того, что необходимо установить самостоятельно: Visual Studio 2022 Build Tools с MSBuild, MSVC v143 для x64 и Windows 10/11 SDK. Лоадер не скачивает и не запускает установщик Visual Studio. После установки нажмите «Обновить статус». Первая сборка может занять несколько минут. После обновления игры выполните шаги обновления SDK в интерфейсе.

Режим обновления запускает игру напрямую; работа без подключения к сети не гарантируется. Использование модификаций может нарушать правила игры и привести к блокировке аккаунта.

## Исходники

Код портативного интерфейса и подготовки — в `portable/`. Архив проекта и SDK — в релизе `v2.0.2`. Хеш архива внедряется в программу при сборке через GitHub Actions; в исходнике используется заполнитель `__PACKAGE_HASH__`.
